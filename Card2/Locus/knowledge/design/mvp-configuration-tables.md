## Content
# 《一人旅途》MVP 配置表（v0.1）

本文件是基础游戏的唯一数值与内容来源。它落实已确认的规则，并为尚未制作的内容提供第一版可直接录入的数据。数值平衡可在测试后调整，但任何调整都必须同步更新本表、实施计划和对应测试预期。

## 1. MVP 范围与阶段边界

| 项目 | MVP 配置 |
|---|---|
| 区域 | 草原、密林；各 4 层，第四层为区域首领 |
| 卡牌 | 40 张：攻击、防御、策略、战术、后勤各 8 张 |
| 伙伴 | 8 名；战斗队伍为主角加最多 3 名伙伴 |
| 敌人 | 10 种：草原 5 种（含首领）、密林 5 种（含首领） |
| 事件 | 20 个：每区 10 个 |
| 遗物 | 8 件 |
| 建设 | 2 座营地建筑、3 座城镇一级建筑；营地基础服务不计入建筑数 |
| 基础版结束 | 击败密林首领，进入“垂直切片结局” |
| 正式战役胜利 | 完整功能加入高山、荒漠、边境后，击败边境首领；不属于 MVP |
| 明确排除 | 交易、灾害、动态价格、都城、法令、周目解锁、遗产、联网、云存档、分析服务 |

## 2. 全局战斗与战役规则

### 2.1 单位、牌组与回合

| 项目 | 固定规则 |
|---|---|
| 主角 | 名称暂定为“旅人”；最大生命 45；基础指令伤害 6；不可离队 |
| 上阵限制 | 主角固定上阵，最多另选 3 名存活伙伴；后备伙伴不参与战斗但保留生命、疾病、疲劳、受伤和忠诚度 |
| 初始牌组 | `C01 剑击`×4、`C09 格挡`×3、`C17 侦察`×1、`C33 包扎`×1、`C36 急救`×1，共 10 张 |
| 牌组限制 | 最小 10 张、最大 30 张；一张卡仅能选择一次升级分支 |
| 战斗开始 | 将本次牌组洗入抽牌堆，抽 3 张牌，能量设为 3，所有本场临时标记清零 |
| 玩家回合开始 | 结算流血等开始时状态；抽 1 张；若手牌已达 5 张则不抽；能量重置为 3 |
| 玩家回合结束 | 未使用能量清零；未使用手牌保留；结算“回合结束”效果；然后进入敌方回合 |
| 手牌上限 | 5 张；因抽牌以外效果获得手牌时，超出的牌直接进入弃牌堆并在记录中注明 |
| 抽牌堆耗尽 | 将弃牌堆洗回抽牌堆后继续抽取；两者均空时停止抽牌，不视为失败 |
| 护甲 | 单位护甲范围 0–30；普通伤害先扣护甲再扣生命；护甲不在回合结束时清零，战斗结束时清零 |
| 死亡 | 生命降至 0 时立即死亡；主角死亡立刻失败；伙伴死亡永久移出本局；敌人死亡立即移出目标列表 |
| 敌人默认目标 | 无特殊目标说明时，选择当前生命百分比最低的存活上阵单位；同值按主角、招募顺序依次判定 |
| 战斗结束 | 胜利后保留存活单位的当前生命、疾病、疲劳、受伤和忠诚度；清除护甲、流血、士气、围捕、掠夺及所有本场临时标记 |

### 2.2 伤害、治疗与临时标记

| 规则 | 固定结算 |
|---|---|
| 普通伤害 | 先应用增减伤，再由护甲吸收，剩余值扣生命；最终伤害不低于 0 |
| 真实伤害 | 无视护甲，直接扣生命；本 MVP 仅流血使用真实伤害 |
| 治疗 | 生命不超过受疾病、受伤修正后的最大生命；不能治疗已死亡单位 |
| 减费 | “下一张牌费用 -1”最低降至 0；只影响本回合下一张实际打出的牌，未使用则回合结束失效 |
| 抽牌加成 | “下回合额外抽牌”与基础抽牌叠加；仍受手牌上限限制 |
| 敌人意图减值 | 只影响该敌人当前显示的下一次意图；伤害、护甲、掠夺量最低降至 0；敌方行动后失效 |
| 集火标记 | 被标记敌人在指定持续时间内每次受到普通伤害额外承受固定值；额外部分同样可被护甲吸收 |
| 诱饵标记 | 被标记敌人的当前意图目标改为主角；若主角死亡或不存在，则回到默认目标规则 |

### 2.3 状态、受伤与忠诚度

| 状态或长期值 | 归属与范围 | 效果 | 结算与移除 |
|---|---|---|---|
| 流血 | 单位；0–5 层 | 单位回合开始时受到等于层数的真实伤害 | 伤害后层数减 1；`C34 净化`、`C12 守护`、`C16 不屈`可移除 |
| 护甲 | 单位；0–30 | 吸收普通伤害 | 战斗结束清零；不能因回合结束清零 |
| 士气 | 玩家队伍共享；0–3 层 | 玩家回合中首次造成普通伤害时，每层使该次伤害 +2 | 触发后清空；`C21 鼓舞`、`C29 集结`获得 |
| 疾病 | 单位；0–3 层，战役长期状态 | 每层使最大生命 -4 | `C34 净化`、营地医棚、城镇医馆移除；战斗结束不清除 |
| 疲劳 | 单位；0–3 层，战役长期状态 | 每层使该单位的护甲上限 -5，且该单位通过“出击命令”造成的伤害 -1 | 营地休整、`C37 调养`、应急口粮升级移除；战斗结束不清除 |
| 围捕 | 单位；0–3 层 | 下一次受到普通伤害时，额外受到 2×层数伤害 | 触发后清空；`C31 战术撤步`移除 |
| 掠夺 | 玩家队伍共享；0–3 层 | 战斗胜利时，每层失去 2 财富；若财富不足则降至 0 | 战斗结束后结算并清空 |
| 受伤 | 单位；无或有，战役长期状态 | 最大生命额外 -25%，向上取整；若当前生命高于新上限则降至新上限 | 仅由列出的敌方“致伤”技能造成；营地医棚或 `C40 医者之手`移除 |
| 忠诚度 | 每名伙伴；0–100，初始 60 | 影响事件选项与离队 | 当一次事件或战斗结算后忠诚度不高于 20，该伙伴离队并保留在结算记录中；主角没有忠诚度 |

### 2.4 长期资源、移动与风险

| 项目 | 初始值 / 范围 | 规则 |
|---|---|---|
| 粮食 | 初始 14；0–30 | 进入草原节点消耗 1，进入密林节点消耗 2；粮食不足时消耗至 0，主角获得 1 疲劳，风险 +2，仍可移动 |
| 财富 | 初始 30；0–999 | 用于事件、建筑和部分奖励；不能为负 |
| 声望 | 初始 0；0–100 | 用于事件条件与城镇建筑前置；不能为负 |
| 建筑材料 | 初始 0；0–99 | 用于建筑；主要来自精英、首领和特定事件 |
| 风险 | 每个区域初始 0；0–10 | 草原每次移动 +1，密林每次移动 +2，进入精英节点额外 +1，营地节点结算后 -2，最低为 0 |
| 风险阈值 | 达到 10 时 | 当前节点结算完成后，风险重置为 5，并强制触发对应区域的“危机伏击”；该次强制遭遇不占据新的地图层 |
| 区域过渡 | 草原首领胜利后 | 进入城镇，保留资源、牌组、存活伙伴、遗物、建筑与长期状态；然后进入密林起点 |
